# On Cue

A role-based, next-action coordination prototype for episodic television production.

## What it does

On Cue gives each person only the information needed for the current setup and next camera roll:

- Where they need to be
- When they are needed
- What action they own
- Whether the setup is ready, at risk, or on hold

## Demo scenario

**Harbor Unit · Episode 104 · Shoot Day 12**

All productions, people, characters, locations, schedules, tasks, and workflow data in this prototype are fictional.

## Core demo path

1. Start in the 1st AD view and see Setup 14B on hold.
2. Switch to Gaffer and mark lighting ready.
3. Switch to Talent Assistant or Wardrobe and mark talent ready.
4. Return to the 1st AD view.
5. Approve camera roll.
6. Open Agent Activity to see event routing and authorization decisions.

## Run locally

```bash
npm install
npm run dev
```

## Prototype boundaries

- Local fictional demo data only
- No real production data
- No external APIs
- No authentication
- No AI model calls
- No performance scoring or surveillance
- Human production leadership remains in control of operational decisions

## Prototype notice

This is a fictional workflow demonstration. It does not use or represent real production data, call sheets, people, characters, locations, schedules, or internal workflows from FBI, Universal Television, Wolf Entertainment, CBS Studios, or any other production.
